# 🏥 Hospital Performance & Patient Analytics Dashboard

## 📌 Project Overview
This project is a Power BI analytics dashboard designed to help hospital management monitor
patient flow, doctor workload, admissions trends, and billing performance.

## 🎯 Business Objective
To provide a centralized dashboard that enables data-driven decision-making for hospital operations,
resource planning, and financial analysis.

## 🧩 Business Problem
Hospital data is scattered across multiple systems, making it difficult to:
- Track patient admissions
- Analyze trends
- Monitor doctor workload
- Evaluate billing and insurance performance

## 🛠 Tools & Technologies Used
- Power BI
- SQL
- Excel
- Data Modeling
- DAX

## 📊 Key KPIs
- Total Patients : 28K
- Total Doctors : 22K
- Total Admissions : 28K
- Average Length of Stay : 15.48
- Average Billing Amount : 25.47K
- Billing by Insurance : 706.20M

## 📈 Dashboard Features
- Interactive slicers (Hospital, Year, Doctor, Gender, Admission Type)
- KPI Cards
- Line Chart for Admission Trends
- Bar Chart for Department Performance
- Donut Chart for Insurance Billing
- Stacked Charts for Gender & Blood Group Analysis

## 📂 Project Files
- Power BI Report (.pbix)
- Dataset (CSV)
- Business Requirement Document (BRD)
- SQL Queries
- Dashboard Screenshots

## 📌 Business Insights
- Emergency admissions peak during mid-year months
- Certain departments have higher average length of stay
- Insurance-based billing contributes major revenue
- Doctor workload is uneven across departments

## 🚀 Business Impact
- Improved hospital resource planning
- Better doctor workload distribution
- Faster decision-making
- Enhanced billing visibility
